🎲 Dice Game

A fun and interactive Dice Game built with HTML, CSS & JavaScript — perfect for practicing DOM manipulation, game logic, and user interaction skills.

This project lets players roll dice and see random results, create game-play interactions, and learn JavaScript basics through a simple browser game.

⸻

🕹️ How to Play
	1.	Click the Roll Dice button.
	2.	A random number between 1 and 6 is generated and shown using dice graphics.
	3.	See the result on screen — you could add scoring, win/lose logic, or extend the game further if you like.

(Adjust these steps if your implementation has scoring or multiplayer rules.)

⸻

💻 Features

✅ Simple, interactive dice roll logic
✅ Random number generation using Math.random()
✅ Updates the UI with the dice result
✅ Built using Vanilla JavaScript, no frameworks required

This approach makes the project great for beginners learning core JavaScript concepts like DOM manipulation and event handling.  ￼

⸻

🛠️ Built With
	•	HTML5 – Markup for the game layout
	•	CSS – Styles and animations for UI
	•	JavaScript – Game logic and interactivity

💡 Get Started Locally

🧰 Prerequisites

You need a modern web browser (Chrome, Firefox, Edge, etc.).

📥 Install & Run
	1.	Clone the repo

git clone https://github.com/Adedamola99/Dice-Game.git
cd Dice-Game


	2.	Open the game
Open index.html in your browser to start playing.

No installation step or server is needed since this is a static web project.  ￼
